## BUG-001　邮箱未做唯一性校验

| 字段 | 内容 |
|---|---|
| 缺陷编号 | BUG-001 |
| 缺陷标题 | 注册时邮箱未做唯一性校验，多个账号可绑定同一邮箱 |
| 所属模块 | 注册模块 |
| 严重程度 | 一般 |
| 优先级 | P1 |
| 缺陷状态 | 新建 |
| 发现版本 | v1.0 |
| 复现步骤 | 1. 用 alice + same@x.com 注册成功；2. 再用 bob + same@x.com 注册 |
| 预期结果 | 第二个账号提示"邮箱已被注册" |
| 实际结果 | 两个账号都注册成功 |
| 备注 | 需求文档未明确邮箱是否唯一，需与产品确认后决定是否修复 |

## BUG-002　用户名大小写敏感，可注册外观相同账号

| 字段 | 内容 |
|---|---|
| 缺陷编号 | BUG-002 |
| 缺陷标题 | 用户名区分大小写，`zhangsan` 与 `Zhangsan` 可同时注册 |
| 所属模块 | 注册模块 |
| 严重程度 | 一般 |
| 优先级 | P2 |
| 缺陷状态 | 新建 |
| 发现版本 | v1.0 |
| 复现步骤 | 1. 注册 `zhangsan` 成功；2. 注册 `Zhangsan` 成功 |
| 预期结果 | 视为同一用户名，提示"用户名已存在" |
| 实际结果 | 两个账号都注册成功，易导致用户混淆、重名冒用 |
| 备注 | 需求未明确是否忽略大小写，建议统一转小写后判重 |

## BUG-003　登录无失败次数限制，存在暴力破解风险

| 字段 | 内容 |
|---|---|
| 缺陷编号 | BUG-003 |
| 缺陷标题 | 登录接口无失败次数限制 / 验证码，可被暴力破解 |
| 所属模块 | 登录模块 |
| 严重程度 | 严重 |
| 优先级 | P0 |
| 缺陷状态 | 新建 |
| 发现版本 | v1.0 |
| 复现步骤 | 连续 5 次用错误密码调用 `/api/login` |
| 预期结果 | 达到阈值后锁定账号或要求验证码 |
| 实际结果 | 每次都仅返回 401，无任何锁定/限流机制 |
| 备注 | 安全类缺陷，建议增加失败次数限制 + 账号锁定 + 图形验证码 |
