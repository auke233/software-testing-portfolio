# 测试用例（用户管理系统）

> 用例格式：用例编号 / 用例标题 / 前置条件 / 测试步骤 / 预期结果 / 优先级 / 设计方法
> 优先级：P0=核心流程，必须通过；P1=重要；P2=一般

**需求规则速查（用例设计的依据）：**
- 用户名：必填，3~20 位，只能包含字母、数字、下划线，且不可重复
- 密码：必填，6~20 位，必须同时包含字母和数字
- 邮箱：必填，需符合邮箱格式
- 确认密码：必须与密码一致
